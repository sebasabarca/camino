# App

Next.js 15 + TypeScript + Tailwind. See the root `README.md` for how content gets here and how to run it.

- `lib/db.ts`: all database access (server only). `data/course.db` is read-only content; `data/progress.db` is created on first use.
- `app/page.tsx`: placeholder that lists the pilot units. The real design comes next.
